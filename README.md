# 🐍 Projetos Acadêmicos em Python

Repositório dedicado aos projetos, exercícios e desafios desenvolvidos em **Python** durante minha graduação em **Ciência da Computação na UniRuy Wyden**.

O objetivo é registrar minha evolução em programação, praticar os conceitos estudados em sala e manter um portfólio organizado dos trabalhos acadêmicos.

## 📚 Conteúdos praticados

- Lógica de programação e algoritmos
- Variáveis, tipos de dados e operadores
- Entrada e saída de informações
- Estruturas condicionais e de repetição
- Funções e organização de código
- Resolução de problemas com Python

## 📁 Projetos

| Projeto | Descrição | Conceitos |
| --- | --- | --- |
| [Cadastro Acadêmico](./cadastro_academico.py) | Recebe nome, idade e duas notas, calcula a média e informa a situação do aluno. | `input`, `print`, conversão de tipos, operadores e `if/else` |

> A lista será atualizada conforme novos projetos forem desenvolvidos.

## ▶️ Como executar

1. Instale o [Python 3](https://www.python.org/downloads/).
2. Clone este repositório ou baixe os arquivos.
3. Abra a pasta no VS Code ou em um terminal.
4. Execute o projeto desejado, por exemplo:

```bash
python cadastro_academico.py
```

Em alguns sistemas, o comando pode ser `python3`.
